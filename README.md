# Busy Bee's Planner

A retro pixel-art weekly planner built with vanilla HTML, CSS, and JavaScript.

## Features

- **7-day weekly calendar** with editable day cards
- **Goal of the Week** section to stay focused
- **Pixel art** bees, carrots, and flags drawn on canvas
- **Animated clouds and flowers** for a cozy vibe
- **Auto-save** using localStorage -- your notes persist across sessions
- Retro **Press Start 2P** font for that 8-bit feel

## Usage

Just open `index.html` in your browser. Click any day card or the goal section to start typing -- everything saves automatically.

## Tech

Single-file app, no dependencies, no build step. Pure HTML + CSS + JS.
